# Faraz Travels & Packers Website

This is a basic website I built for a travel and packers & movers service.
The main goal was to create something simple, clean, and useful for real customers.

## About

The website allows users to:

* Book travel services (taxi, tours, tickets, etc.)
* Request packers & movers service
* Connect directly on WhatsApp for faster communication

## Features

* Travel booking form
* Packers & movers request form
* WhatsApp integration
* Responsive design
* Clean UI
* Basic form validation

## Tech Used

* HTML
* CSS
* JavaScript
